# 三种分块方式的检索指标对比

同一批 44 份 PDF，用三种分块方式各建一个独立的 Milvus 库，跑同一套标注问题，
检索链路与生产一致（bge-m3 向量 + jieba BM25，RRF 融合，可叠加 bge-reranker-v2-m3 重排），
差异只来自分块方式。

## 一、实验设置

| 项目 | 内容 |
| --- | --- |
| 语料 | `data/gov_doc/` 44 份政务/能源 PDF（全量，无采样） |
| 测试问题 | `tests/evaluation/questions.json` 16 道，人工标注相关片段 |
| 评测脚本 | `tests/evaluation/run_chunk_compare.py`（产物目录 `tests/results/chunk_compare/`） |
| 向量模型 | bge-m3（1024 维） |
| 重排模型 | bge-reranker-v2-m3 |
| 检索方式 | 稠密向量 + BM25 → RRF 融合 → 可选重排 |
| 片段过滤 | 有效字符数 < 5 的噪声片段丢弃 |
| 表格片段 | 作为三种方式共同的常数基线加入（`表格基线=True`） |
| 图片描述 | 不参与对比（需视觉模型，对三种方式是同一份常数） |

## 六、结论

- **语义分块全面领先**：在两种检索模式下，语义分块的所有指标均为三者最高，
  重排后 nDCG@5 达 0.4632，是递归字符分块（0.1172）的约 4.0 倍。
- **重排对所有方式都有正收益**，语义分块提升最明显（MRR +0.1163）。
- **递归字符分块表现最差**：平均片段长达 385 字符，
  固定长度切断语义单元，向量表征被稀释。
- 语义分块片段最短（平均 137 字符）却效果最好，说明粒度贴合语义边界比片段长度更重要。

> 注：`element` 策略在 `38-china-power-supply-development-report-2026-cn.pdf` 上未切出片段
> （该文档基本是整页扫描件，三种方式在该文档上都只产出极少内容：语义 6 条、递归 3 条、元素 0 条）。
> 经核对，16 道测试问题无一以该文档为标注来源，不影响本次对比结论。
