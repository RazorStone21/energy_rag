# 三种分块方式的检索指标对比

同一批 44 份 PDF，用三种分块方式各建一个独立的 Milvus 库，跑同一套标注问题，
检索链路与生产一致（bge-m3 向量 + jieba BM25，RRF 融合，可叠加 bge-reranker-v2-m3 重排），
差异只来自分块方式。

> **本轮（2026-09-14 第二次重跑）换掉了判分函数，数值与此前各版都不可比。**
> 旧版 `is_relevant` 的子串判断漏了空白归一化（同一函数里的 `_ngrams` 却做了），
> PDF 抽取的断行位置随排版变化，导致长片段被系统性判为未命中。修正后三种方式的
> 指标全面上升，且**第二、三名互换**：旧结论里的"递归字符分块近乎失效"是判分
> 规则造成的假象，它并没有坏。修正见 `tests/evaluation/run_retrieval_eval.py`。

## 一、实验设置

| 项目 | 内容 |
| --- | --- |
| 语料 | `data/gov_doc/` 44 份政务/能源 PDF（全量，无采样） |
| 测试问题 | `tests/evaluation/questions.json` 16 道，人工标注相关片段 |
| 评测脚本 | `tests/evaluation/run_chunk_compare.py`（产物目录 `tests/results/chunk_compare/`） |
| 向量模型 | bge-m3（1024 维） |
| 重排模型 | bge-reranker-v2-m3 |
| 检索方式 | 稠密向量 + BM25 → RRF 融合 → 可选重排 |
| 片段过滤 | 有效字符数 < 20 的噪声片段丢弃（`config.toml` 的 `splitting.min_chars`） |
| 命中判定 | 忽略空格和换行后的子串包含关系，或 3-gram Jaccard ≥ 0.6 |
| 表格片段 | 作为三种方式共同的常数基线加入（`表格基线=True`） |
| 图片描述 | 不参与对比（需视觉模型，对三种方式是同一份常数） |
| 跨页处理 | 带页码的正文先按句合并成整篇再切分，页码回填到片段（见附注二） |

## 六、结论

- **语义分块仍然全面最优**：两种检索模式下，12 项指标均为三者最高。重排后
  hit@1 达到 0.7500（16 题命中 12 题），MRR 0.8021。
- **优势幅度是温和的，不是压倒性的**：重排后 MRR 是递归字符分块的 1.31 倍、
  element 的 1.77 倍。此前"约 30 倍"的说法源自判分规则的缺陷，不成立。
- **三种方式的名次为 semantic > recursive_char > element**，修正判分后
  递归字符分块回到第二名。它与 element 的差距同样温和（MRR 1.36 倍）。
- **重排对所有方式都有正收益**，且提升幅度与分块质量正相关：语义分块
  MRR +0.1688，递归字符 +0.1096，element +0.0858。这说明重排是在已有候选上
  做精排，底子越好，它能发挥的空间越大。
- 语义分块片段数最少（1382）却效果最好，说明粒度贴合语义边界比片段数量重要。

> **附注一：判分规则的修正改变了全部数值。** 旧版 `is_relevant` 逐字比较子串，
> 而同一函数的 `_ngrams` 已剥离空格和换行——两处口径不一致。PDF 抽取的断行随
> 排版变化，标注与片段对同一句话的断行往往不同，于是明明命中的结果被判为未命中；
> 长片段另有一条不利：Jaccard 的并集分母被块长撑大。修正后纯向量 hit@1 的变化：
> semantic 0.4375 → 0.5625、recursive_char 0.0000 → 0.4375、element 0.1250 → 0.3125。
> **三者都上升，其中 recursive_char 升幅最大（+0.4375），但升幅与平均块长并不成比例**
> （element 平均块长比 semantic 短，升幅却更大），具体机制未查明。因此**本报告与
> 2026-09-14 首轮、以及 2026-09-11 首版的数值都不可比。**
>
> **附注二：三者的跨页处理并不对等。** `semantic` 与 `recursive_char` 都走生产
> `Chunker`，切分前会把同一文档的相邻页面按句合并成整篇（修复前实测 21.6% 的
> 正文片段尾部是跨页残句，修复后 3.6%）；`element` 走独立的元素聚合路径，
> 不经过该步骤。横向差距中包含这部分结构性差异。
>
> **已知局限：** 语料中另有少量页眉噪声（如「04 | 中国绿色燃料发展报告（2026）」，
> 11/1271 条，集中在 1 份文档）未被清除，与片段切分质量无关。评测样本仅 16 道题，
> 单题翻转即会明显移动指标，解读时请留出余量。

> 注：`38-china-power-supply-development-report-2026-cn.pdf` 基本是整页扫描件，
> 三种方式在该文档上都只产出 1 条内容。经核对，16 道测试问题无一以该文档为标注来源，
> 不影响本次对比结论。三种策略均无解析或切分失败的文件。
