# 前端页面

原生 HTML / CSS / JavaScript，没有构建步骤，也没有第三方依赖。
由 `src/server/app.py` 挂载在 `/`（首页）和 `/static`（静态资源）下。

## 启动

在项目根目录运行：

    python main.py serve            # 需要先装 Web 依赖，见根目录 README
    python main.py serve --demo     # 不加载模型，用编造数据预览界面

改完这里的文件刷新浏览器即可，不需要重新启动服务；
浏览器缓存了旧脚本时用 `Ctrl+Shift+R` 强制刷新，或修改 `index.html` 里的 `?v=1`。

## 文件职责

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：侧边栏、顶栏、消息区、输入区 |
| `assets/style.css` | 设计令牌、布局、组件样式、明暗主题、响应式 |
| `assets/app.js` | 状态、接口调用、SSE 解析、消息与面板渲染、会话与索引状态 |
| `assets/markdown.js` | 轻量 Markdown 渲染，流式输出用 |
| `assets/icons.js` | 内联 SVG 图标 |

## 换主题色

所有颜色、圆角和阴影都集中在 `assets/style.css` 顶部的 `:root` 与
`[data-theme="dark"]` 两段里，改这两个地方即可，不要在各个组件里写死颜色。

品牌色是宝蓝色（Sapphire）：亮色主题用 `--brand: #0F52BA`，
深色主题提亮为 `--brand: #5B8DEF` 以免深蓝压在深灰上看不清。

版式参考通义千问，但**全站只用纯色，不使用任何渐变**，界面里也不放 emoji；
所有图标都是 `icons.js` 里的内联线性 SVG。新增样式时请沿用这条约定。

## 两条渲染规则

- **模型输出的答案**走 `markdown.js`：先把整段文本做 HTML 转义，再做白名单转换，
  因此模型输出里的标签只会以文字显示。
- **检索到的原文**（来源面板）只用 `textContent` 赋值，不经过 Markdown 渲染。

两者不能混用，改渲染相关代码时请保持这条边界。

## 已知取舍

- Markdown 支持标题、粗体斜体、行内代码、代码块、有序与无序列表、引用、分隔线、
  管道表格和链接；嵌套列表按单层渲染，表格不做列宽对齐。
- 流式渲染只把「已完结的段落」转成 HTML 追加，尾部未完成的部分保持纯文本，
  `done` 事件到达后再用服务端返回的完整答案整体替换一次。
- 「停止」按钮只停止接收，模型仍会把这一轮生成完，界面上有对应说明。
- 会话历史保存在浏览器 `localStorage` 里，最多保留 30 条；
  发给模型的历史轮数与字数由后端 `[conversation]` 配置控制。
